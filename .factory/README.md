# ajantrik Software Factory

Generated by `factory render` from `.factory/config/` (the source of truth: `factory.yaml`,
`agents/*.md`, `skills/*/SKILL.md`). Edit those with `factory studio` or by hand, then run
`factory render`.

- Runtime: **claude-cli**. Interactive: `/factory "<request>"` in Claude Code. Headless:
  `factory run "<request>"`.
- Delivery: **none** after a human approval.
- Dashboard: `.factory/ui.sh` (http://127.0.0.1:8000/dashboard.html). Studio: `factory studio`.
- Job commands without the installed CLI: `python3 .factory/factory.py --help`.
- Guards: `python3 -m unittest discover -s .factory/security/tests`.

Job state lives in `.factory/jobs/` (gitignored); job worktrees in
`../ajantrik-factory/`.
